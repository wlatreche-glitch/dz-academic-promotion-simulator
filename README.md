# dz-academic-promotion-simulator
🇩🇿 محاكي تفاعلي ذكي لحساب نقاط التأهيل الجامعي والترقية لرتبة أستاذ (البروفيسورا) في الجزائر، متوافق مع الدورة 53 وقرارات وزارة التعليم العالي والبحث العلمي الأخيرة.
# 🇩🇿 محاكي التأهيل والترقية الجامعية بالجزائر (إصدار 2025 - 2026 التفاعلي)

أداة استشارية ذكية طُوّرت خصيصاً لمساعدة الأساتذة والباحثين الجزائريين المقبلين على **التأهيل الجامعي (Habilitation)** أو **الترقية لرتبة أستاذ (Professorat)** في حساب نقاط ملفاتهم ومحاكاة السيناريوهات الحسابية بدقة متناهية وسرية تامة.

## 🌟 الميزات الجوهرية للنظام الحسابي

* **التشخيص الذكي الفوري (Customized Conditions):** يتكيف المحرك الرياضي برمجياً بمجرد اختيار نوع الترقية (تأهيل أو بروفيسور) والميدان (علوم وتكنولوجيا S&T أو علوم إنسانية SHS) ليعرض ويطبق الشروط الإقصائية المناسبة لملفك تلقائياً.

* **الملف الإداري التفاعلي:** قائمة تفاعلية مدمجة (Interactive Checklist) مقتبسة من الدليل التنظيمي الرسمي لتتبع مدى جاهزية وثائقك الرقمية قبل الرفع في منصة PROGRES.

* **دعم علاوات اللغة الإنجليزية:** احتساب دقيق لعلاوات التدريس والمطبوعات والمقالات المنشورة باللغة الإنجليزية وفق تعليمات الوزارة الوصية الأخيرة.

* **دعم مشاريع الابتكار والمؤسسات الناشئة:** دمج بنود القرار (شهادة - مؤسسة ناشئة) لمنح نقاط تأطير استثنائية ونقاط إنشاء مؤسسة مبتكرة.

* **محرك الأوزان الدقيق وتجنب تداخل المؤلفين:** يطبق النظام المعاملات القانونية لترتيب المؤلفين.

* **التقرير المحدث القابل للطباعة:** توليد تقرير رقمي يحاكي الجداول الرسمية للوزارة وتصديره بصيغة PDF بضغطة زر واحدة بفضل التنسيق المخصص للطباعة `@media print`.

## 📋 المراجع القانونية المعتمدة في الخوارزمية

تم بناء المعادلات الرياضية ومصفوفات التحقق وفق المراجع التنظيمية الرسمية لـ **وزارة التعليم العالي والبحث العلمي بالجزائر**:

1. **شبكة التقييم الخاصة بالترقية إلى رتبة أستاذ** بعنوان **الدورة الثالثة والخمسون (53)** للجنة الجامعية الوطنية.

2. **شبكة التقييم ودليل الإجراءات الرسمي** للحصول على **التأهيل الجامعي للأستاذ الباحث والباحث الدائم** (القرار 804 والمعدل بالقرار 493).

## 🚀 طريقة النشر والتشغيل السريع لملفك

بما أن المشروع خفيف ولا يتطلب قواعد بيانات خلفية، يمكنك تشغيله بعدة طرق مجانية:

### النشر المباشر عبر GitHub Pages

1. قم برفع ملف `index.html` وملف `README.md` إلى مستودعك الجديد.
2. اذهب لإعدادات المستودع الخاص بك على GitHub (Settings).
3. من القائمة الجانبية اختر **Pages**.
4. تحت خيار **Build and deployment**، اضبط الفرع (Branch) ليكون `main` أو `master` ثم اضغط **Save**.
5. سيظهر لك رابط موقعك المباشر في ثوانٍ معدودة.
